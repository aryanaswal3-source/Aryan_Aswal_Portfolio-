## 🌐 Deploying to GitHub Pages

1. **Initialize and push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Aryan Aswal Developer Portfolio"
   git branch -M main
   git remote add origin https://github.com/aryanaswal3-source/Aryan_Aswal_Portfolio.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/aryanaswal3-source/Aryan_Aswal_Portfolio`
   - Click on **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Branch**, select `main` and root `/` folder.
   - Click **Save**.
   - Your website will be live in ~60 seconds at:
     `https://aryanaswal3-source.github.io/Aryan_Aswal_Portfolio/`
